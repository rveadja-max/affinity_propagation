```r
library(apcluster); library(cluster)
ari <- function(a, b) {               # ARI de Hubert & Arabie, en attendant aricode (D3)
  t <- table(a, b); n <- sum(t); s <- sum(choose(t, 2))
  sa <- sum(choose(rowSums(t), 2)); sb <- sum(choose(colSums(t), 2))
  e <- sa * sb / choose(n, 2); (s - e) / ((sa + sb) / 2 - e)
}
for (G in c(1234L, 20261101L)) {
  x <- scale(iris[, 1:4]); s <- negDistMat(x, r = 2)
  a0 <- apcluster(s, q = 0, seed = G)
  D  <- as.matrix(dist(x))^2
  p  <- pam(as.dist(D), k = length(a0@exemplars), diss = TRUE)
  cout <- function(cl) sum(sapply(unique(cl), function(k) {   # coût au médoïde a posteriori
    i <- which(cl == k); min(colSums(D[i, i, drop = FALSE])) }))
  set.seed(G); km <- kmeans(x, 3, nstart = 25)
  w <- cutree(hclust(dist(x), "ward.D2"), 3)
  print(c(AP = cout(labels(a0, "enum")), PAM = cout(p$clustering),
          KM = cout(km$cluster), Ward = cout(w)))            # 147,62 / 146,68 / 146,79 / 151,84
  # Tirages faits AVANT la boucle : apcluster(seed = G) remet le générateur global à G
  set.seed(G); idx <- replicate(100, sort(sample(150, 120)), simplify = FALSE)
  stopifnot(length(unique(vapply(idx, paste, "", collapse = ","))) == 100)
  ra <- rk <- numeric(100)
  for (b in 1:100) {
    i  <- idx[[b]]
    aa <- apcluster(negDistMat(x[i, ], r = 2), q = 0, seed = G)
    ra[b] <- ari(labels(aa, "enum"), labels(a0, "enum")[i])
    set.seed(G + b)
    rk[b] <- ari(kmeans(x[i, ], 3, nstart = 25)$cluster, km$cluster[i])
  }
  print(round(c(graine = G, AP = mean(ra), KM = mean(rk)), 3))  # 1234 : 0,929 / 0,938 ; 20261101 : 0,917 / 0,940
}
```

### 6.2 Procédure du 04/11 : mettre fiche, slides, TP et scripts sur `main` sans le rapport partiel

Pourquoi : toute branche existante contient `Report/Affinity_propagation_rapport.qmd` (base 0a9566e), donc aucune fusion directe ne convient. On passe par une branche de livraison créée depuis `main`, et on y recopie les commits avec `git cherry-pick`. Le cherry-pick **garde l'auteur d'origine** (seul le « committer » change), donc la traçabilité est conservée.

```bash
git fetch origin
git switch -c livrables/oral origin/main
# 1. Lister les commits à livrer, du plus ancien au plus récent, hors fusions :
git log --reverse --no-merges --format='%h %an %s' origin/main..origin/Application_Iris -- Application tp
git log --reverse --no-merges --format='%h %an %s' origin/main..origin/Rapport -- .gitignore README.md fiche slides analyses resultats figures analyse_litterature
# 2. Les recopier (TP d'abord, puis le reste), dans l'ordre affiché :
git cherry-pick <h1> <h2> ...
# 3. Contrôles avant fusion :
git diff --name-only origin/main livrables/oral | grep '^Report/'   # doit être VIDE
git log --format='%an' origin/main..livrables/oral | sort | uniq -c # les deux noms
git ls-tree --name-only livrables/oral | grep -x -e .gitignore -e README.md   # les DEUX lignes
git ls-tree -r --name-only livrables/oral | grep -E '^(CLAUDE\.md|\.claude/|quality_reports/)'  # doit être VIDE
Rscript tp/Application_Iris.R                                       # le TP tourne depuis cette branche
# 4. Après validation à deux : fusion par le binôme lui-même
git switch main && git merge --no-ff livrables/oral && git push origin main
```

Points d'attention :
- Un commit qui touche à la fois `Report/` et un autre dossier ne peut pas être recopié proprement. C'est la raison de la règle « un commit = un dossier ». En cas d'erreur, utiliser `git cherry-pick -n <h>`, puis `git restore --staged --worktree Report/`, puis `git commit -C <h>`, qui reprend le message et l'auteur.
- `.gitignore` et le README modifié (` M` dans `git status`) sont commités chacun seul sur `Rapport` (§6, première action git) ; le filtre de l'étape 1 inclut `.gitignore README.md`, donc leurs commits apparaissent dans la liste et sont recopiés **en premier**, avant tout autre fichier. Le contrôle `git ls-tree … | grep -x` de l'étape 3 vérifie qu'ils sont bien sur la branche de livraison.
- **Repli** si la procédure bloque après 20h : fusionner `Rapport` dans `main` avec le message « rapport en cours, version finale le 10/11 ». C'est une entorse à D7 = b, à signaler aux enseignants, et c'est préférable à un dépôt incomplet à 23h59.
