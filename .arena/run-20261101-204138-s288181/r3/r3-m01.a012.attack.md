ATTACK 1 [MAJOR] The guiding question is adopted word for word, but the plan never tests two of the factors it names (similarity, standardisation)
Where: § 4.4 « La question directrice est celle du README (`README.md:26-29`). Le plan et l'introduction du rapport la reprennent mot pour mot. Elle parle de **stabilité** : Q5 est donc traitée… » ; § 5, table 5.1–5.6 ; § 5.5 « 5.5 Stabilité (Q5) ».
Problem: The question it adopts (README.md:26-29) asks « comment les choix de **similarité** et de **préférence** influencent-ils le nombre, la stabilité et l'interprétabilité des clusters ». In every sub-part of § 5, the similarity stays fixed at `negDistMat(r = 2)` on standardised data. Only q and λ vary. Nothing in the plan produces a result on how the similarity choice matters. On top of that, the project's own Q5 is « Standardisation et stabilité » (`questions_recherche.md:80-82`: « la standardisation (z-score ou données brutes) change-t-elle les exemplaires choisis par AP ? »), and `methodologie.md:53` and `:68` list standardisation as an experimental factor (« avec et sans standardisation »). The plan quietly keeps only the stability half of Q5 and drops the raw vs z-score comparison, without listing that cut as a decision. The cut is also missing from the « couper dans cet ordre » list and from § 7. Result: the report's conclusion « réponse courte à la question directrice » cannot answer half of the question the plan locks in, and the checklist (§ 8) never checks for it. Fix: either add a small similarity/standardisation experiment (raw vs `scale()`, and/or r = 1 vs r = 2), or reword the question before it gets « reprise mot pour mot ».

ATTACK 3 [MINOR] The reproducibility check `Rscript analyses/0x_*.R` runs only the first script
Where: § 8 checklist « `Rscript analyses/0x_*.R` régénère tous les CSV depuis un clone propre ».
Problem: The shell expands the glob to `Rscript analyses/00_config.R analyses/01_sensibilite_q.R …`. Rscript runs only the first file and passes the others to it as `commandArgs()`. So the command runs `00_config.R` and nothing else, and the « régénère tous les CSV » box gets ticked without any CSV being regenerated. This is the plan's main test that « every number comes from a script ». It needs a `for f in analyses/0[1-9]_*.R; do Rscript "$f"; done` loop or a `run_all.R`.
