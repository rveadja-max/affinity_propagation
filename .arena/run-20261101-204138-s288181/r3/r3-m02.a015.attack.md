It never says whether `lam_main` is 0.9 (the `apcluster` default) or 0.5 (Frey & Dueck), and it gives no value for `seed_main`. Where: line 275: "`Species` … n'apparaît qu'en argument des fonctions ARI et NMI. On peut le contrôler avec `grep -n Species tp/*.R`."
Problem: (a) False alarm: the plan's own evaluation steps need `Species` outside ARI/NMI. §3.1 shows the cross-table cluster × `Species`, and the TP is asked for a "comparaison rapide" (line 243), which in practice means `table(labels, iris$Species)`. The check cannot certify "aucune fuite", which is a non-negotiable CLAUDE.md rule.
