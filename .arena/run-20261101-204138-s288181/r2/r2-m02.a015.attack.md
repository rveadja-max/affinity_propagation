ATTACK 6 [MINOR] Completion check 1 cannot pass as written
Where: part 5 « Fini quand : supprimer `Report/resultats/` puis lancer … `quarto render` redonne exactement le même PDF » ; §3 contrôle 1
Problem: XeLaTeX writes /CreationDate, /ModDate and an ID into every PDF, so two renders of the same source are never byte-identical. A literal « exactement le même PDF » check always fails. The check should compare the CSV files (`md5sum Report/resultats/*.csv`) or the extracted text (`pdftotext`), not the PDF.
