### 2.2 Enjeux techniques

Ce sont les points que le jury peut attaquer. Le rapport doit les traiter de front.

1. **Le nombre de clusters n'est pas « trouvé » par AP.** Il découle de la préférence s(k,k) et de la similarité. Mesuré sur Iris standardisé, `negDistMat(r = 2)`, `seed = 1234` :
   - réglage par défaut (q = médiane) : 9 clusters, 210 itérations ;
   - q = 0 : 3 clusters ; q = 0,05 à 0,2 : 5 clusters ; q = 1 : 149 clusters.
   *(Commande : script `check.R` lancé pour ce document. Ces chiffres ne doivent entrer dans un livrable qu'une fois produits par un script du dépôt.)*
2. **Les défauts d'`apcluster` diffèrent de l'article.** `lam = 0.9` (contre 0,5 chez Frey & Dueck), `maxits = 1000`, `convits = 100`, `nonoise = FALSE`, `seed = NA`. *(Vérifié dans `?apcluster`, apcluster 1.4.14.)*
3. **`apcluster` n'est pas strictement déterministe.** Il ajoute un petit bruit à la matrice de similarité, sauf si `nonoise = TRUE`. Sans `seed`, deux lancements peuvent différer. Sur Iris avec q = 1 : 149 clusters avec bruit, 148 avec `nonoise = TRUE`. La phrase « AP est déterministe à données et paramètres fixés » (`analyse_litterature/methodologie.md:18`) est donc à corriger pour `apcluster`.
4. **Choisir q pour obtenir 3 clusters serait une fuite d'étiquettes.** q = 0 donne exactement 3 clusters sur Iris ; le présenter comme « le bon réglage », c'est utiliser les espèces pour régler AP.
5. **La comparaison doit être équitable.** Même données, même standardisation, même dissimilarité, mêmes k, graines fixées. Point concret : `cluster::pam` utilise par défaut la distance euclidienne, **pas** son carré. Pour comparer à AP avec `negDistMat(r = 2)`, il faut lui passer la matrice des distances au carré.
6. **AP a une critique publiée.** Brusco & Köhn (commentaire dans *Science*, fichier local dont le nom cite à tort Frey & Dueck) rapportent qu'une heuristique du p-médiane obtient souvent une erreur plus faible. Le rapport doit en parler, et rapporter nos résultats même s'ils sont défavorables à AP. *(Source A, lue par `analyse_litterature/questions_recherche.md`, non revérifiée ici.)*
7. **Iris ne prouve rien sur la performance.** Il valide la chaîne de traitement. Un second jeu (Wine) est prévu mais pas encore téléchargé ; sa licence n'est pas vérifiée (`methodologie.md:34`, `:108`).

#### Partie 3 — Fondements mathématiques

- **À faire**, dans cet ordre (c'est l'ordre du cadrage) :
  1. **Similarité** : s(i,k) = −‖xᵢ − xₖ‖² ; pourquoi la standardiser ; lien avec `negDistMat(r = 2)`.
  2. **Préférence** s(k,k) : son rôle sur le nombre d'exemplaires ; médiane ou minimum conseillés par Frey & Dueck.
  3. **Fonction objectif** : maximiser la somme des similarités aux exemplaires sous la contrainte « un exemplaire se choisit lui-même » ; lien avec le problème p-médiane / k-médiane, NP-difficile (`cadre_theorique.md:24-25`).
  4. **Stratégie d'optimisation** : passage de messages max-sum sur un graphe factoriel ; formules de r(i,k), a(i,k), a(k,k) ; règle de décision ; critère d'arrêt ; **amortissement λ des messages** (pas des préférences) ; pas de garantie d'optimum global ; oscillations dans les cas dégénérés.
  5. **Hypothèses probabilistes** : dire clairement ce qu'il en est. AP ne suppose pas de modèle de mélange comme les mélanges gaussiens ; max-sum peut se lire comme une recherche du maximum a posteriori. **Les deux phrases sont à sourcer dans Frey & Dueck 2007 avant d'être écrites** ; d'ici là, elles sont des hypothèses (C).
  6. **Complexité** : O(n²) en mémoire et par itération pour une matrice dense.
- **Sources** : Frey & Dueck 2007 (pages du PDF citées dans `cadre_theorique.md`) ; Brusco & Köhn pour le p-médiane ; Leone et al. pour la complexité (prépublication, publication en revue non vérifiée, `cadre_theorique.md:58`).
