ATTACK 2 [MAJOR] The script for the "fair comparison" sets up a measure that favours K-means and Ward, and asks for a dissimilarity K-means cannot take
Where: §4.2 `02_iris_comparaison.R` « à k fixé par AP : AP, `pam`, `kmeans(nstart = 25)`, Ward. Somme des dissimilarités aux représentants » ; §3.1 Enjeu 3 « sur les mêmes données et avec la même dissimilarité ».
Problem: The representatives of `kmeans` and Ward are centroids, which are not observations. With the squared Euclidean distance (`negDistMat(r = 2)`, the one `methodologie.md:66` keeps), the sum of distances to the centroid is always ≤ the sum to any observation of the cluster. So « somme des dissimilarités aux représentants » systematically favours K-means and Ward over AP and `pam`, which are limited to real exemplars. That is not the same criterion. Also, `kmeans()` takes no dissimilarity matrix at all, so « la même dissimilarité » cannot be applied to it as written. The plan has to say which criterion to compute for each method: the p-median on medoids recomputed for K-means and Ward, or the intra-cluster SSE for everyone. It also has to say how `pam` gets squared distances (`pam(dist(x)^2, k, diss = TRUE)`). Otherwise whoever writes 02 has to guess, and the comparison table will be biased. That breaks the « comparaison équitable » rule in the task.
