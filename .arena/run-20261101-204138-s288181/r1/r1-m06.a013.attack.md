ATTACK 1 [MAJOR] The main comparison is run at k = 3 through q = 0, the leakage trap the document itself warns about
Where: §3.1 enjeu 1 ("présenter `q = 0` comme « le bon réglage » parce qu'il redonne 3 espèces serait une fuite d'étiquettes") vs §4.3 Ch. 6.3 ("pour au moins 2 valeurs de k produites par AP (défaut et `q = 0`)")
Problem: On Iris, q = 0 gives k = 3, the number of species. The annex output confirms it (`3 5 5 5 6 9 16 33 149`). So one of the two rows of the headline comparison table is at k = 3. `analyse_litterature/methodologie.md:72` forbids exactly this: "Fixer k = 3 utiliserait les étiquettes pour régler les méthodes, ce qui est une fuite". The plan gives no label-free reason to pick q = 0 (for example "minimum of `preferenceRange()`, fixed before any look at the labels, as Frey & Dueck suggest"). It also does not say this choice must be written down before the results are seen. The anti-leakage "fini quand" of Ch. 5 does not catch it either. A jury question like "why q = 0? Because it gives 3?" has no prepared answer. The rule is non-negotiable (CLAUDE.md), and the plan leaves it ambiguous in the very table it calls the core result.
